# Nightly Ventures configs

Configs, scripts and other files from the [Nightly Ventures](https://www.nightlyventures.com) videos. Each folder belongs to a tool or build; the write-up for each video explains what the files do.

| Video | Folder | Write-up |
|---|---|---|
| [Self-Host Moltbot in a Proxmox VM (The Secure Way)](https://youtu.be/DG7p0BfO6UI) (Jan 2026) | [`openclaw/`](openclaw/) | [Post](https://www.nightlyventures.com/p/self-host-moltbot-on-proxmox) |
| [3 GPUs, 1 Local AI Agent. Here's Where It Breaks.](https://youtu.be/-fmpLgSs2M8) (Feb 2026) | [`openclaw/`](openclaw/) | [Post](https://www.nightlyventures.com/p/run-openclaw-with-local-models-via-ollama) |
| [RGB Rack Lighting with ESPHome](https://www.youtube.com/watch?v=G8DM5r7OdXc) | [`esphome-rack-controller/`](esphome-rack-controller/) | [Post](https://www.nightlyventures.com/p/autonomous-rgb-rack-lighting-with-esphome-and-quinled) |

Each folder's README lists the versions the files were tested with. Found something that no longer works? Open an issue.
